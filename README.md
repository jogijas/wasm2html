# @jogijas/wasm2html

A lightweight Node.js utility to compile and embed WebAssembly (`.wasm`) files directly inside a standalone, browser-ready HTML file using Base64 encoding. It automatically intercepts framework-level fetch requests targeting `.wasm` files to ensure seamless runtime compatibility.

## Features

- 📦 **100% Self-Contained:** Converts binary WebAssembly modules into inline Base64 strings embedded inside a single HTML bundle.
- ⚓ **Fetch Interception Polyfill:** Overrides `window.fetch` inside the generated HTML to automatically detect and intercept browser calls for `.wasm` files, serving the embedded module seamlessly.
- ⚡ **Helper Instance Loader:** Bundles a built-in `loadEmbeddedWasm()` utility function for painless manual instantiation.
- 🧩 **Custom JS Injection:** Append any custom frontend orchestration script alongside the module execution layer.

## Installation

Install the package via npm:

```bash
npm install @jogijas/wasm2html
```

## Usage

```javascript
const fs = require('fs');
const wasm2html = require('@jogijas/wasm2html');

// 1. Read your compiled WebAssembly binary into a Buffer
const wasmBuffer = fs.readFileSync('./app.wasm');
// 2. Read your javascript file into a Buffer
const customJS = fs.readFileSync('./app.js');
// 3. Generate the standalone HTML document string
const htmlContent = wasm2html(wasmBuffer, customJS);
// 4. Save the generated HTML document to disk
fs.writeFileSync('./index.html', htmlContent);

console.log('Successfully bundled WASM into index.html!');
```

## Inside the Generated HTML

The output file generated by `@jogijas/wasm2html` ships with two main internal primitives injected into the global browser space:

### 1. Automated Fetch Interception
If your front-end framework or initialization scripts make a traditional network request for a `.wasm` file, the injected polyfill intercepts it:

```javascript
// This standard web request will automatically return your embedded module
fetch('anything.wasm')
  .then(response => WebAssembly.instantiateStreaming(response))
  .then(obj => ...);
```

### 2. Manual Helper: `loadEmbeddedWasm(importObject)`
Alternatively, you can skip fetch networking mechanisms altogether and instantiate your compiled binary straight out of memory:

- **Arguments:** `importObject` *(Object, Optional)* — The standard WebAssembly imports object containing environment functions or memory channels.
- **Returns:** `Promise<Object>` — Resolves into the `instance.exports` object containing your compiled WebAssembly logic.
